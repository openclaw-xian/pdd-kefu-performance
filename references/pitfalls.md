# 踩坑（pdd-kefu-performance）

| 现象 | 根因 | 正确做法 |
|---|---|---|
| 打开页面是「服务数据」 | 默认页签不是客服绩效 | 先点「客服绩效数据」，校验正文含「客服绩效详情」 |
| 日期面板点箭头后消失 | 组件行为 | 重开面板、回读 `RPR_headerSelector` 月份再继续 |
| 9/1–9/19 点不动 | 平台只保留最近 **62 天**（三家店一致） | 预检 `from < 今天-62` 直接 `date_before_retention`；从 9/20 起选 |
| 账号多时截图漏上半截 | 固定高度不够 | 动态按表格高度截图（≥944，账号多则更高） |
| 空表被当失败/不留证据 | 无数据时直接报错 | **0 行也截图**；md 写「数据状态：无数据」；只有表格结构找不到才 `table_not_found` |
| 重复跑覆盖旧图 | 同数据重截 | 日期/店铺总计相同 → 跳过覆盖；不同 → `.bak-<时间>.png` |
| 部分月份想放同一个月目录 | 自动按 from_to 建目录 | 用 `periodDir:"2026-09"` + `label:"9月20日-9月30日"` 覆盖 |
| 选了日期但数据没变 | 漏点「确认」 | 选起止日 → 确认 → 回读输入值 |
| 把 10 月选成 10/01~11/01 | 误用订单导出的 +1 天规则 | 客服绩效是日期区间：**结束日就是最后一天，不 +1** |
| 右上角「新消息 (N)」挡住表格 | 站内信弹窗 | 点 `ImportantList_close` 关闭后再截图；worker 在开页/切页签/截图前都会尝试关 |
| 截图右边被裁 | 浏览器窗口窄，表格横向超宽 | 用 CDP `Page.captureScreenshot` + `captureBeyondViewport`，宽度 ≥1908，不够再加 |
| 截不到底部/共有N条 | 没滚到底 | `scrollTop = scrollHeight` 后再截 |
| 输出跑到别处 | root/期间命名不对 | `<root>/<店铺>/<期间>/<店铺>-客服绩效-<label>.png` |
| 页面预算 8/8 | 用户标签太多 | worker 先按 profile 重建空间；重建失败才 `page_budget_full` 交回 |
| 刚过 0 点数据不全 | 前一日的客服绩效可能今日 10:00 后才算完 | 跑前一天数据要等 10:00 后 |
| 店铺名不符 | profile 登错店 | 报 `shop_mismatch`，换 profile/登录正确店 |
| 日期回读不一致 | 面板关闭/确认没触发 | 最多 3 次：重开→选日→确认→回读 |
