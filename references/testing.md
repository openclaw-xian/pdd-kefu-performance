# 测试记录（pdd-kefu-performance）

> 环境：Windows + ego lite 0.6.3.14，2026-11-21。店铺匿名化为 A/B/C。

## 1. 单店全链路

| 项 | 结果 |
|---|---|
| 店铺C，2026-10 | 打开客服绩效 → 日期 `2026-10-01 ~ 2026-10-31` → 底部截图 |
| 耗时 | 6.9s |
| 截图 | 1908×944，完整表格，含最右列和「共有 6 条」 |
| 输出 | `店铺C-客服绩效-10月.png` + `客服绩效.md`，落在 `店铺C/2026-10` |

## 2. 多店并行

| 店铺 | 结果 | 耗时 |
|---|---|---|
| 店铺A | done | 8.3s |
| 店铺B | done | 12.4s |
| 店铺C | done | 13.3s |

- 三家产物都落在各自 `<店铺>/<期间>/`，和货款账单/推广花费/订单 CSV 同目录
- 截图均为 1908×944，日期回读一致

## 3. 通知弹窗

- 店铺C 页面出现「新消息 (2)」弹窗，遮住表格右侧
- worker 点 `ImportantList_close` 关闭；重跑后截图无弹窗
- 重跑耗时 12.2s，日期 `2026-10-01 ~ 2026-10-31`

## 4. 已知限制

- 只测了 10 月整月；跨月/跨年未单独测
- 截图尺寸固定 1908×944；页面窗口更窄时靠 CDP 横向宽截图
- 未测 0 行/无数据店铺
- 未测 8/8 页面预算下的 needs 路径（worker 会直接失败并保留页）
- 不导出、不下载客服数据文件
